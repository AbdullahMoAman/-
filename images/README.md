# 🖼️ دليل الصور — Images Guide

ضع صورك في هذا المجلد بالأسماء التالية بالضبط:

| اسم الملف | الوصف | المقاس المقترح |
|---|---|---|
| `hero-kaaba.jpg` | صورة الكعبة المشرفة والمسجد الحرام — للخلفية الرئيسية | 1920×1080 على الأقل |
| `hajj-crowd.jpg` | حشد الحجاج أو طواف | 800×600 |

## ملاحظات
- الصيغ المقبولة: `.jpg` أو `.jpeg` أو `.png` أو `.webp`
- إذا لم تجد الصورة، سيظهر مكانها إطار بسيط بخط منقط ذهبي مع نص "أضف صورة هنا"
- يُفضَّل اختيار صور ذات جودة عالية وإضاءة طبيعية
- تأكد من أن الصور مرخَّصة للاستخدام (Royalty-free)
